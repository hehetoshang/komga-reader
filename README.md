# komga-reader

A framework-light comic image reader extracted from [gotson/komga](https://github.com/gotson/komga) for reuse with page manifests.

> This is an unofficial project and is not affiliated with or endorsed by the Komga project.

The standalone Vue component, demo, extraction notes, and tests are being developed on a feature branch and will be reviewed through a pull request.
